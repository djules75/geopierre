Comment ça marche

Chaque carte part du barycentre de son pays. Déplacez le point ou cliquez sur une carte : l'autre carte répond en direct.

  • Absolu : même distance en kilomètres, même cap.
  • Proportionnel : même fraction du trajet centre → frontière, dans le même cap. La frontière est mesurée dans chaque direction, la règle épouse donc la forme exacte du pays.
  • Fantôme : la silhouette de l'autre pays est posée sur la carte, à taille réelle en mode absolu, déformée pour épouser le pays hôte en mode proportionnel.
  • Balayage : la cible fait un tour complet et dessine, sur les deux cartes, la même « ligne d'horizon ».

Clavier : ← → cap · ↑ ↓ distance · M mode · F fantôme · S balayage · X échanger

Seul le territoire principal (continent + îles proches) sert aux calculs ; les territoires lointains apparaissent en filigrane. Données Natural Earth, aucune connexion requise.
